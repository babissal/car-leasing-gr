## Objective

Implement the Playwright scraper infrastructure (base setup) and the Instacar.gr adapter. The scraper accepts `{ duration, advancePayment }` parameters, applies filters on the site via UI clicks, collects offers from listing cards, visits each offer's detail page for CO2 and services, and returns a `RawOffer[]` that the normalization layer can process. Treats 0 results as an error (ORCH-03).

const INSTACAR_URL = 'https://www.instacar.gr/';
const SOURCE_NAME = 'Instacar';

Export async function scrape({ duration, advancePayment = 0 }):

1. LAUNCH: const { browser, context, page } = await launchBrowser()
   Wrap entire scrape in try/finally { await closeBrowser(browser) }

2. NAVIGATE: await page.goto(INSTACAR_URL, { waitUntil: 'domcontentloaded', timeout: 30000 })
   await addJitter(800, 1500)

3. APPLY FILTERS via UI clicks:
   - Look for a duration/lease-term filter dropdown or button group
   - Click the option matching `duration` months (12, 24, 36, or 48)
   - If advance payment filter exists, select 0 / "χωρίς προκαταβολή"
   - await addJitter(500, 1000) after each filter interaction
   - Wait for results to reload: await waitForResults(page, '[data-testid*="car"], .car-card, article[class*="car"], .listing-item', { timeout: 20000 })
   - If waitForResults returns false: throw new Error('Instacar: results did not load after filter application')

4. COLLECT ALL OFFERS (handle both pagination modes):
   const listingCards = []

   Scroll/paginate loop:
   - Try infinite scroll: scroll to bottom, wait 2s, check if new cards appeared
   - Try "Next page" button: look for button/a matching 'Επόμενη', 'next', '›', '→'
   - Collect card elements matching the listing card selector
   - Stop when: no new cards after scroll OR no next-page button found
   - Max iterations: 10 (safety cap)

5. EXTRACT LISTING DATA from each card:
   For each card, extract (use page.evaluate or locator methods):
   - brand: text of brand/make element
   - model: text of model element
   - carType: body type text (SUV, Sedan, etc.)
   - fuelType: fuel type label text
   - monthlyPrice: price text (e.g. "350 €/μήνα")
   - kmPerYear: km text (e.g. "20.000 km/χρόνο")
   - sourceUrl: href of the card's link element (full URL)
   Store as raw objects; do NOT normalize yet.

6. EXTRACT DETAIL DATA (visit each offer's detail page):
   For each raw listing card (limit: first 50 to avoid excessive time):
   - await page.goto(sourceUrl, { waitUntil: 'domcontentloaded', timeout: 20000 })
   - await addJitter(300, 800)
   - Extract: co2Text (g/km value), servicesText (list of included services as joined string)
   - Push { ...listingData, co2Text, servicesText } to results

7. NORMALIZE each raw result to CommonOffer:
   - monthlyPrice: normalizePrice(raw.monthlyPrice, true) — Instacar shows VAT-included prices
   - fuelType: normalizeFuelType(raw.fuelType)
   - servicesIncluded: parseServices(raw.servicesText || '')
   - co2gKm: parseCO2(raw.co2Text)
   - kmPerYear: parseInt((raw.kmPerYear || '').replace(/\D/g, '')) || null
   - Use createOffer({ source: SOURCE_NAME, sourceUrl: raw.sourceUrl, brand, model, carType, fuelType, monthlyPrice, advancePayment, durationMonths: duration, kmPerYear, servicesIncluded, co2gKm, scrapedAt: new Date().toISOString() })
   - Skip offers where validateOffer(offer).valid is false (monthlyPrice null)

8. ORCH-03 check:
   if (offers.length === 0) throw new Error(`Instacar: scrape returned 0 offers for duration=${duration} — possible site structure change or block`)

9. Return offers array

Note: Exact CSS selectors for Instacar.gr must be determined by inspecting the live site. Use broad selectors first (data-testid, aria-labels, semantic elements) and fall back to class-based selectors. Add a comment block above each selector group noting what it targets.
