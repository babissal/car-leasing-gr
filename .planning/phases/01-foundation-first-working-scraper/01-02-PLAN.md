<action>
Create lib/normalize.js with these exports:

normalizePrice(rawPrice, vatIncluded=true):
- Parse string prices: remove '€', '.', ',', whitespace; convert to float
- If vatIncluded=false: multiply by 1.24 (add 24% Greek VAT)
- Return number rounded to 2 decimal places, or null if parsing fails

normalizeFuelType(rawLabel):
- Input: Greek or English string from scraped site
- Map (case-insensitive) to English enum:
  - 'βενζίνη', 'petrol', 'gasoline', 'benzine' → 'Petrol'
  - 'πετρέλαιο', 'diesel', 'gasoil' → 'Diesel'
  - 'υβριδικό', 'hybrid', 'mild hybrid', 'full hybrid' → 'Hybrid'
  - 'plug-in', 'phev', 'plug in hybrid', 'υβριδικό plug' → 'PHEV'
  - 'ηλεκτρικό', 'electric', 'bev', 'ev' → 'Electric'
  - Anything else → 'Unknown'
- Use String.prototype.normalize('NFC') before matching

parseServices(rawText):
- Input: string or array of strings describing included services
- Return { insurance: boolean, maintenance: boolean, tyres: boolean }
- Match (case-insensitive): 'ασφάλεια', 'insurance', 'ασφ' → insurance=true
- Match: 'συντήρηση', 'maintenance', 'service' → maintenance=true
- Match: 'ελαστικά', 'tyres', 'tires', 'gume' → tyres=true
- Default all to false if no match

parseCO2(rawValue):
- Parse "120 g/km", "120", 120 → 120 (number)
- Return null if not parseable or if rawValue is null/undefined/empty
</action>
<acceptance_criteria>
- lib/normalize.js exists
- `node -e "const n=require('./lib/normalize'); console.log(n.normalizePrice('1.250,00 €', true))"` prints 1250 (or 1250.00)
- `node -e "const n=require('./lib/normalize'); console.log(n.normalizeFuelType('Ηλεκτρικό'))"` prints 'Electric'
- `node -e "const n=require('./lib/normalize'); console.log(n.normalizeFuelType('plug-in hybrid'))"` prints 'PHEV'
- `node -e "const n=require('./lib/normalize'); console.log(n.parseServices('Ασφάλεια, Συντήρηση'))"` prints { insurance: true, maintenance: true, tyres: false }
- `node -e "const n=require('./lib/normalize'); console.log(n.parseCO2('120 g/km'))"` prints 120
- `node -e "const n=require('./lib/normalize'); console.log(n.parseCO2(null))"` prints null
</acceptance_criteria>
</task>
