## Objective

Implement Playwright scrapers for the 4 remaining Greek leasing sites. Each adapter follows the same pattern as scrapers/instacar.js: navigate to listing page, collect offers, visit detail pages as needed, normalize to CommonOffer, throw if 0 results.

## Site Summary (from research)

| Site | Listing URL | Duration support | Price format |
|------|-------------|-----------------|--------------|
| Spotawheel | /subscribe | Flex (monthly) or Fixed (36/48) | ex-VAT |
| Executivelease | /leasing-offers/prosfores/oles | 36/48/60 months | ex-VAT |
| Ayvens | /el-gr/prosfores-leasing/ | detail page selection | ex-VAT |
| Easyrental | /leasing/prosfores-kainouria/ | detail page | incl. services |

## Tasks

Each task: live-inspect site → write scraper → node --check.

Implementation notes per site:
- Spotawheel: filter by `subscription_installment` URL param; return all fixed-plan offers (skip Flex)
- Executivelease: UI click duration filter (36/48/60); for 12/24 requests use 36 as fallback
- Ayvens: collect detail page links, visit each, extract duration options
- Easyrental: includes insurance+maintenance in monthly fee → servicesIncluded.insurance=true, maintenance=true

## must_haves
- [ ] Each scraper file passes `node --check`
- [ ] Each exports `async function scrape({ duration, advancePayment })`
- [ ] Each throws (not returns empty) when 0 valid offers found
